================================================================================
BACKEND API INTEGRATION
================================================================================

Required Endpoints:
  - POST /api/upload → { upload_id, sha256 }
  - POST /api/analyze/{uploadId} → { job_id }
  - GET /api/sample/{uploadId}/status → { status, sample_id }
  - GET /api/results/{sampleId} → Full analysis JSON
  - GET /api/threat-intel/{sampleId} → { family, indicators, circl_report }
  - WebSocket /ws → Real-time pipeline events

Required Response Fields:
  - step1.apk_size, step1.duration
  - dissection.classes[], dissection.permissions[]
  - step5.c2_indicators[] (with type, value, threat_level)
  - step6.threat_chains[]
  - step7.risk_score, step7.llm_assessment
  - step8.obfuscation_score, step8.reflection_score, step8.crypto_score
  - timeline{}

HOW TO DEPLOY
================================================================================

1. Copy files to your DroidForensix project:

   cp components/*.jsx frontend/src/components/
   cp styles/*.css frontend/src/styles/

2. Install dependencies (if not done):

   cd frontend
   npm install

3. Run dev server:

   npm run dev

4. Verify in browser (http://localhost:5173):
   - Upload tab visible
   - Analysis tab works after upload
   - Code Dissection tab shows 179 classes ✅

5. Build for production:

   npm run build
