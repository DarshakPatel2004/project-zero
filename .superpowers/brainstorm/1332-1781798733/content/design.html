How each requested feature will be wired into the Analysis result tabs.

Data flow summary

  • Overview tab: uses already-loaded pipeline result.
  • Dissection tab: SmartDissection fetches /dissection/classes + /obfuscation; source viewer fetches /dissection/code/{class}.
  • Manifest tab: fetches /dissection/manifest.
  • C2 tab: fetches /threat-intel.
  • Obfuscation tab: ObfuscationView fetches /obfuscation and posts to /deobfuscate.
